# iOS application

Reserved for the Compose Multiplatform iOS application host, Xcode project,
platform lifecycle, Keychain adapter, file pickers, sharing, signing, and App
Store packaging. SwiftUI and UIKit may be used for platform-specific surfaces
behind shared feature and domain interfaces.

No iOS product code has been implemented yet. Domain, data, and synchronization
logic must be consumed from the shared Kotlin Multiplatform modules rather than
reimplemented here.
