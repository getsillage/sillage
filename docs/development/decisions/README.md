# Architecture Decision Records

ADRs record significant, cross-module, hard-to-reverse technical or process choices.

## Format

File name: `YYYY-MM-DD-<topic>.md`

Required sections only:

1. **Context**
2. **Decision**
3. **Consequences**

Link any superseded ADR. Do not use ADRs for task plans, routine implementation details, or TODOs.
